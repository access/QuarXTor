# GLOSSARY

- `T-001` MAP: Structural gate DAG with DoD/evidence rules only.
- `T-002` EXEC: Operational cursor and resume instructions.
- `T-003` LEDGER: Append-only NDJSON transitions and decisions.
- `T-004` Gate: Readiness condition with explicit dependencies and closure evidence.
- `T-005` ClusterSpec: Typed cluster configuration object (mode, policy, transports, federation).
- `T-006` Discovery Triad: `announce/query/resolve` contract for availability.
- `T-007` Bounded Broadcast: Mesh-wide request with TTL/fanout/dedupe/rate limits.
- `T-008` Universal Envelope: Stable JSON output shape for CLI machine output.
- `T-009` Smart Archive: ZIP-compatible non-disk bundle with QuarxTor extensions.
- `T-010` Optimizer: Analyzer/planner/executor subsystem for dedup/compression efficiency.
